# AivibeBoard

Одностраничная доска задач (аналог Trello / лёгкой Jira) с лендингом, входом через Supabase, ИИ-разбиением эпиков, inbox Telegram и базой знаний по проекту.

Приложение открывается на лендинге. Доска доступна после входа или регистрации. Задачи, документы и inbox по-прежнему живут в **IndexedDB** этого браузера: аккаунт Supabase не синхронизирует доску между устройствами.

## Языки

Интерфейс: **русский, английский и иврит**. Переключатель **RU | EN | עב** стоит в шапке лендинга, формы входа и доски. Выбор пишется в `localStorage` (`aivibeboard.locale`) и переживает перезагрузку.

Для иврита у `<html>` выставляются `lang="he"` и `dir="rtl"`: вёрстка зеркалится, жёлтая полоска лендинга уезжает на правый край.

Переводится chrome UI и сообщения об ошибках. Названия колонок, задач и прочие данные IndexedDB остаются как есть.

Словари и провайдер: `src/i18n/`.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

Без `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` клиент не стартует: `src/services/supabase.ts` бросает ошибку при создании клиента.

## Переменные окружения

Скопируйте `.env.example` в `.env` (файл `.env` в git не попадает):

```env
VITE_OPENAI_API_KEY=
VITE_OPENAI_MODEL=gpt-4o-mini
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

| Переменная | Назначение |
|------------|------------|
| `VITE_SUPABASE_URL` | URL проекта Supabase. Обязательна для входа и регистрации. |
| `VITE_SUPABASE_ANON_KEY` | Публичный anon-ключ. Обязателен. Не путайте с `service_role`. |
| `VITE_OPENAI_API_KEY` | Ключ для «ИИ-постановки». Пустое значение включает локальный fallback. |
| `VITE_OPENAI_MODEL` | Модель OpenAI. По умолчанию в примере — `gpt-4o-mini`. |

Без ключа OpenAI раздел «ИИ-постановка» разбивает текст локально: по строкам и пунктам.

**Важно:** значения `VITE_*` попадают в бандл браузера. Anon-ключ Supabase для этого и рассчитан (доступ ограничивают политики). Ключ OpenAI в продакшене лучше прятать за прокси (см. Roadmap).

### Supabase Auth

В проекте Supabase включите Email provider. Приложение использует только email и пароль:

- вход — `signInWithPassword`;
- регистрация — `signUp`, пароль от 6 символов, ссылка подтверждения ведёт на `window.location.origin`;
- выход — кнопка «Выйти» в шапке доски.

Если в проекте включено подтверждение email, после регистрации сессии ещё нет: на форме появится просьба открыть письмо. После перехода по ссылке приложение само откроет доску.

В настройках Auth добавьте адрес приложения (для локальной разработки обычно `http://localhost:5173`) в **Site URL** и **Redirect URLs**.

## Экраны

1. **Лендинг** (`LandingPage`) — возможности, шаги и призыв к действию. Если сессия уже есть, кнопки ведут сразу на доску («Открыть доску»), иначе на форму входа.
2. **Вход и регистрация** (`AuthPage`) — переключение вкладок на одной форме. Ошибки Supabase показываются на выбранном языке.
3. **Доска** — рабочее приложение. Кнопка «Сайт» в шапке возвращает на лендинг, не выходя из аккаунта. При уже существующей сессии доска открывается сразу, минуя лендинг.

## Разделы доски

| Раздел | Описание |
|--------|----------|
| Доска | Канбан, drag-and-drop, CRUD задач и колонок |
| База знаний | Загрузка `.md`, `.txt`, `.pdf` (PDF — ограниченный текст) |
| ИИ-постановка | Эпик → подзадачи с исполнителями; контекст из выбранных документов |
| Telegram | Inbox, симуляция сообщений, создание задач |
| Команда | Участники для назначения и ИИ |
| Настройки | Имя проекта, секрет webhook |

## Telegram webhook (будущее)

Контракт тела POST для `ingestTelegramMessage`:

```json
{
  "secret": "ваш-секрет-из-настроек",
  "chatId": "-100123",
  "fromUsername": "user",
  "text": "Текст задачи"
}
```

В MVP ingest вызывается из SPA; для реального бота нужен небольшой сервер, который принимает апдейты Telegram и пересылает payload (или пишет в общее хранилище).
